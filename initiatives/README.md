# Your projects go here

Each design gets its own folder, for example `initiatives/remote-holder/`.
The agent creates it when you start a project (see
[guides/01-start-a-project.md](../guides/01-start-a-project.md)).

A project folder usually grows to hold:

- `README.md`, `BRIEF.md`: what the part is for, in your words.
- `status.md`: where it stands now. `log.md`: what happened, by date.
- `MEASUREMENTS.md`: measurements of the real object it must fit.
- `DESIGN.md`: axes, assumptions and the decisions you made.
- `*.scad`: the model. `*.py`: scripts that export, check and render it.
- `reference/`: your sketches and photos.
- `exports/`: STL files and check reports. `renders/`: pictures.
- `PRINT.md`: the print and assembly sheet. `observations.md`: what you reported after printing.

See [examples/keypad-sculpture/](../examples/keypad-sculpture/) for a finished one.
