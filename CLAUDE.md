## Claude Code notes

- The kit's skills load from `.claude/skills/`, which links to `skills/`.
  Use them by name, for example the `start-a-project` skill.
- To look at a render, read the PNG file; check it before describing it.
- For the optional multi-agent workflow, a subagent (the Agent tool) can take
  a work item; see `guides/runbook-multi-agent.md`.
- Ask before running `bin/setup`, since it installs software.
